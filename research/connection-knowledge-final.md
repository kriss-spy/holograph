## Discovery resources and verification boundaries

- AkiLove: Japanese dictionary spellings, archive search and off-channel articles locate primary sources. Dictionary stories without source links remain secondary.
- AZKi Song Database: public performance data and song timestamps locate musical collaborations. Its unit/guest mode covers original songs; it is not an exhaustive collaboration stream index. Per-song singers do not establish an entire unit's roster.
- Holodex: talent Collabs tabs and stream-to-clip-to-source navigation locate original uploads and alternate viewpoints. Collaborator tags and fan clip titles are leads, not sufficient proof of a performer-used unit name.
- Hololive Fan Wiki: direct article requests work. Its MediaWiki API rejects default client user agents with an explicit contact-policy message; an identified `HolographResearch/1.0 (https://github.com/kriss-spy/holograph)` user agent successfully retrieves public API responses. A web-reader 403 is not evidence that the wiki itself is unavailable.

Detailed final evidence and unresolved decisions are retained in the AZKi, Korone/Aki and Holodex follow-up reports produced alongside this reconciliation.
